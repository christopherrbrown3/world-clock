World Clock.

62 watch and clock faces, drawn as live inline SVG and set to real time in cities around the world. One standalone HTML file — no build step, no server, no dependencies, nothing fetched from the network.

Type to search, then use the arrow keys and Enter to add a city.

    Your zone

    Every face is inline SVG drawn from reference photographs of the real object — no images, no sprites, no server rendering. Times come from the browser clock and the IANA time zone database via Intl, so daylight saving is always current and cities re-sort themselves west to east as offsets change. Brand, product and character names are used descriptively to identify the objects depicted.
